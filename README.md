# Sahara Welfare Foundation

A responsive coming-soon page built around a patchwork quilt (drawn entirely in CSS), a short values section, and an accessible welcome-note dialog. No build step or dependencies required.

## Run locally

```sh
npm run dev
```

Open http://localhost:3000. Set `PORT` to use another port.

## Deploy

Serve `index.html`, `styles.css`, `script.js`, and `favicon.svg` from any static hosting provider. `server.mjs` is provided for local preview or Node hosting.

Fonts are loaded from Google Fonts, with local serif and sans-serif fallbacks. All illustrations are included in the page; no external images are required. The page collects no visitor data.
